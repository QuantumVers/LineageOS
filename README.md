# LineageOS

**Every Human. One Family Tree.**

The first attempt to map the complete lineage of humanity — connecting 120 billion lives across 300,000 years.

## What Is This?

LineageOS is an AI-powered global ancestry graph that maps every human relationship across history into one interconnected family tree. This repo contains the working prototype — a single-page web app you can open in any browser.

## Quick Start

1. Clone this repo
2. Open `lineageos.html` in your browser
3. Search for "Elliot Goldman" to explore the demo family tree

No server, no build step, no dependencies (beyond Google Fonts loaded from CDN).

## Features

- **Lineage Explorer** — Interactive, zoomable family tree visualization
- **Relationship Engine** — Find the connection path between any two people
- **Evidence Layer** — Every relationship backed by source evidence with confidence scores
- **Timeline View** — Scroll through your ancestors across centuries
- **DNA Analysis** — Genetic ancestry breakdown with haplogroup mapping
- **Global Migration Map** — Animated migration paths across continents
- **AI Predictions** — ML-predicted missing ancestors with confidence levels
- **Architecture Vision** — Data pipeline and product roadmap

## Tech Stack

- Pure HTML/CSS/JS (single file, no framework)
- Canvas API for tree visualization and animations
- Google Fonts (Inter)
- Designed for desktop browsers (responsive mobile support included)
